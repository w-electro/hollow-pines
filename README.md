# PawTales

A browser game for kids who love roleplay: your own characters become figures with personalities, and they talk to each other and to you.

The AI runs entirely in the player's browser (WebGPU), so there is no server, no account, and nothing a kid types or draws leaves their device.

**Status:** early design. The live page is a placeholder.

Live: https://w-electro.github.io/pawtales/
