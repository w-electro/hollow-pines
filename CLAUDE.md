# Camp Hollow Pines (repo: hollow-pines) — working rules

- **Nothing on C:.** The C: drive is full. Every download, model cache, install, build output and scratch file goes on D: (scratch work in `D:\W\_scratch\`). Point model caches at D: explicitly (Transformers.js `env.cacheDir`, `HF_HOME`); run npm with `npm_config_cache=D:/W/_scratch/.npm-cache`; Playwright drives the installed Chrome with its profile and `--disk-cache-dir` on D:.
- **Zero budget.** Everything free and open source. No paid APIs, no paid hosting. AI runs in the player's browser (WebGPU); hosting is GitHub Pages from `main`.
- **Players are 13+ (horror).** Content level matches Roblox horror rated 13+: mild blood is fine; no detailed injuries, torture, or self-harm. Safety is enforced in code (input check, streaming output check, memory guard, self-harm care note) — never rely on the prompt alone. Run `node tests/play.mjs` after changing dialogue code.
- **IP:** the concept is inspired by camp slashers, but no names, characters or marks from Friday the 13th. The brothers are Mason and Silas.
- **Model:** Gemma 3 1B (`onnx-community/gemma-3-1b-it-ONNX`, q4f16, ~760 MB). A spike on 2026-10-03 found it held character and stayed safe best; LFM2 1.2B was faster but flat; Qwen3 1.7B looped. It is weak at following concrete requests ("help me find the exit"), so game mechanics should not depend on the model understanding instructions.
- **Local vs live:** an inline script in `index.html` writes the import map: on localhost, libraries from `node_modules` and models from `/models/` (served by `serve.py` from D:) with no browser caching; on Pages, jsDelivr and Hugging Face with normal caching.
- **Voice:** Kokoro-82M (`dtype: 'q8'`, WASM, in `src/voice-worker.js`) — its fp16/q4 variants output NaN on WebGPU, don't switch. Synthesis is ~2× slower than real time even with 4 threads, so: fixed lines are prefetched, live lines are spoken sentence by sentence, and every `speakAs` has a `patience` after which a stale line is dropped. One shared speech queue for all characters. Multi-threading needs cross-origin isolation: `serve.py` sends the headers locally, `coi.js` (service worker) adds them on Pages.
- **Tests:** `node tests/story.mjs` must reach `state: win` with 0 errors after any gameplay change. Pass paths to `tests/check.mjs` without a leading slash (Git Bash rewrites `/x` into `C:/Program Files/Git/x`).
- **Dialogue** runs in `src/ai-worker.js`; safety stays on the main thread (`src/safety.js`) and checks every streamed token. Replies are capped (`npc.maxSentences`) and generation stops when the cap is reached. Hidden example exchanges (`npc.examples`) shape the voice more than rules do. Help questions to Mason get a written hint (`masonHint()` in main.js) — never let the model give directions. Run `node tests/safety.mjs` after changing anything in dialogue or safety; it must print ALL SAFE.
- **Known:** while a character thinks the frame rate drops (~75 fps, worst frame ~100 ms) because the model and the scene share the GPU.
